# Público-alvo

O site deve falar principalmente com empresas que compram processo ou peça, não com o consumidor final.

| Segmento | O que pode procurar |
| --- | --- |
| Indústrias metalúrgicas | Terceirização de processos |
| Fabricantes de máquinas | Peças e componentes |
| Indústria automotiva | Componentes metálicos |
| Fabricantes de equipamentos | Corte, dobra e soldagem |
| Empresas de comunicação visual | Peças e estruturas metálicas |
| Fabricantes de móveis | Componentes e acabamentos |
| Empresas de manutenção industrial | Peças de reposição |

Esses segmentos se distribuem nas duas frentes de [06-frentes-comerciais.md](06-frentes-comerciais.md): quem precisa de uma etapa terceirizada e quem precisa da peça ou do conjunto fabricado.
